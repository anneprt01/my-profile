# Photos de fiches PMU

Déposer ici les photos "normales" (pas pixelisées) des deux fondateurs
ensemble, prises sur place au moment du test de chaque PMU.

Convention de nommage suggérée : `<id-du-pmu>.jpg` (le `id` est celui
utilisé dans `src/data/pmus.json`), puis renseigner le champ
`photoFiche` de ce PMU avec `/assets/fiches/<id-du-pmu>.jpg`.

Ne pas confondre avec les portraits pixel art du dossier `../rain/`, qui
servent uniquement à l'effet de pluie au clic.

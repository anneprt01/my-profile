# Portraits "pluie"

Déposer ici les portraits pixel art utilisés pour l'effet de pluie qui
tombe quand on clique sur un PMU déjà testé :

- `anne_rain_final.png` — portrait d'Anne (déjà fourni dans le brief).
- `fondateur2_rain_final.png` — portrait du deuxième fondateur, à ajouter
  dès qu'il sera prêt.

Pour activer un nouveau portrait dans la pluie, il suffit d'ajouter une
entrée dans `src/data/rainPortraits.js` — aucun autre changement de code
n'est nécessaire, la pluie pioche déjà aléatoirement dans cette liste.
